# 第一次Linux课程任务

- 安装虚拟机工具，推荐vmware workstation, 创建虚拟机，并在虚拟机中安装ubuntu，或者centos，或者其他linux发行版。
- 下载putty.exe，或者xshell，或者secureCRT等终端连接工具。
- 安装好linux虚拟机后，核对openssh服务是否已开始，通常是开启了的。然后使用putty等软件连接上自己的虚拟机。至此完成了所有课程环境的要求。
- 在你的主操作系统，如windows，mac,或者linux上安装VS code. 同时在 Extension插件列表中，安装Markdown Preview Enhanced。
- 在vscode中，使用markdown语法做一个首次作业完成情况的清单。格式不限。
